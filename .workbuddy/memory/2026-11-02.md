## YooAsset tag 语义（讨论中确认，供以后参考）
- `GetDownloadListByTags`：**无 tag 的 bundle 任何按 tag 下载都会带上**（基础内容）；有 tag 的只在命中时才下；`AssetTags` 支持 `;` 多 tag，粒度 = collector（路径）。
- 下载界面按"功能包"= 一个 tag 最省事；图集等公共资源不打 tag。地址清单方案（`CreateBundleDownloader(locations, recursiveDownload:true)`）只在"包内挑零散资源/不想维护依赖归属"时才更合适。

## 图集 v2 绑定修复（2026-11-02 晚）
- 症状：`Common.spriteatlasv2` 生成后 Inspector 无预览。Editor.log 里 `[UISpriteAtlas] 找不到 m_ImporterData.packables`，即 packables 为空。
- 根因：`SpriteAtlasAsset` 的原生字段拿不到 SerializedProperty 路径（`new SerializedObject(atlas).FindProperty("m_ImporterData.packables")` 恒 null），所以 BindFolder 一直走 error 分支。
- 修法：直接改资产 YAML —— 把 `packables:` 那一项换成 `- {fileID: 102900000, guid: <文件夹GUID>, type: 3}`（文件夹 fileID 固定 102900000），再 `ImportAsset(ForceUpdate)`，导入后**回读文件确认 guid 还在**（Unity 可能按导入结果重写）。
- 已确认 `SpriteAtlasAsset` 在 UnityEditor.dll 里有 `Add/Remove/Save/Load/SetIncludeInBuild` 等成员，但没有公开的"创建到路径"静态方法，所以仍用 YAML 模板。
- 教训：Unity 6 的 `.spriteatlasv2` 只要 packables 为空就等于空图集，预览区什么都没有，且不报错。
- 第二个原因（同日发现）：24 张 png 全是 `spriteMode: 2`(Multiple) 且 `sprites: []` —— Multiple 无切片不产生任何 Sprite，图集里收不到东西。工具里加了 `EnsureSpriteImport`：用 `LoadAllAssetsAtPath` 看有没有 Sprite 子资产来判断，没有就强制 `textureType=Sprite + spriteImportMode=Single`（避开已废弃的 `TextureImporter.spritesheet`）。
- 注意 `using System;` 会和 `UnityEngine.Object` 撞名（CS0104），所以 `StringComparison` 全部写成 `System.StringComparison`。
