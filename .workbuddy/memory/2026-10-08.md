## 边走边攻击：上半身遮罩

需求：走路时攻击，下半身播走动画、上半身播攻击动画。

结论：**播放代码不用改，两个前提都已具备，只差一个遮罩资产。**

- 层叠顺序天然正确：`TLAnimationOutput.CompareTracks` 按 `PlaybackLayer` 排（`Base=0 / Action=100`），Action 轨拿到更大的 layer port，压在 Base 层之上 ⇒ 上半身能盖住走动画。
- mask 通路已接：`TLAnimationTrack.Connect:118-122` 会把 `AnimationTrackAsset.avatarMask` 交给 `AnimationLayerMixerPlayable.SetLayerMaskFromAvatarMask`，`isAdditive` 同理走 `SetLayerAdditive`。AvatarMask 按骨骼路径匹配，**Generic rig 同样可用**。
- 逻辑侧已是 Allow：`Role_DummyAttack01-03.asset` 三个动作 `movementPolicy: 0`（Allow）⇒ `BlocksMovement` 为 false，Locomotion 保持 Move、位移照常、Base 层放 Run。默认声明值是 Block，只是这三个资产生成时写的是 0。
- Base/Action 默认并存：只有 Life/Control 命中才 `ExclusiveBase`，动作表现层不独占基础层。

### 新增 `Assets/Editor/Combat/DummyUpperBodyMaskSetup.cs`

菜单 `UxGame/工具/战斗/配置边走边攻击(上半身遮罩)`（priority 525）：从 `Role_Dummy.prefab` 的骨架找 `B-spine`，递归收集其自身及全部子骨骼路径 → 写进 `Res/Timeline/Role/Role_DummyUpperBodyMask.asset` → 挂到 `CharacterCombatProfile.ActionPresentations` 里**所有**动作 Timeline 的动画轨（`isAdditive=false`）。幂等可重跑；只提示不改 `Block` 的动作。

- **AvatarMask 没有 `ClearTransformPaths`**（在 `UnityEngine.AnimationModule.dll` 里 grep 不到，Unity 6 也没有），清空只能 `mask.transformCount = 0`。`AddTransformPath` **只有 `Transform` 重载**（传 string 报 CS1503），用 `AddTransformPath(upperRoot, true)` 递归写入并由 Unity 自己算路径；`CalculateTransformPath` 在 UnityEditor.dll（仅编辑器可用）。
- 编辑器 Timeline 窗口本来就有「移动基底」预览模式（`TimelineWindow.BuildPreviewPlan`）⇒ 选它可直接验收边跑边打，不必进 Play。
